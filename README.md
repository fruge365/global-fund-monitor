## 功能特性

- **顶部导航 + 市场状态**：总览 / 涨跌榜 / 基金列表 / 趋势对比，滚动自动高亮；按真实时区实时判定 A股 / 港股 / 美股 / 日股 的交易状态，并展示刷新时间戳与倒计时进度。
- **市场总览**：今日上涨 / 下跌 / 平均涨跌统计；8 张指数卡片（沪深300、中证500、恒生、纳斯达克100、标普500、道琼斯、日经225、黄金ETF），含点位、涨跌幅、昨收与迷你趋势折线，红涨绿跌。
- **今日涨跌榜**：涨幅榜 / 跌幅榜 TOP6，每 4 秒纵向平滑轮播。
- **基金列表**：国内宽基 / 海外 QDII / 黄金商品三类筛选；列含名称、类型、最新净值、日涨跌、近1月 / 近3月 / 近1年、近30日迷你走势；表头可排序，支持名称 / 代码搜索，手机端自动切换为卡片视图。
- **趋势对比**：多标的选择（最多 6 条），近1月 / 近2周切换，首日归一化为 100，含 100 基准线。
- **视觉与动效**：深蓝底 + 金 / 青点缀、等宽数字、卡片入场动画、点位 odometer 数字滚动、每 6 秒模拟刷新并滚动更新数字。
- **响应式**：适配手机，底部注明数据来源与风险提示。

## 快速开始

项目为静态站点，无需构建，直接用脚本启动本地服务（默认端口 8000）。

### 启动

```bash
bash start.sh
```

- 端口已在监听时直接返回 `0`（不重复启动）。
- 启动成功返回 `0`，启动失败返回 `2`。

### 停止

```bash
bash stop.sh
```

### 手动启动（不使用脚本）

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

启动后访问 `http://localhost:8000/`，根路径直接返回 `index.html`。

## 技术说明

- 纯前端实现，无框架、无构建步骤，浏览器直接运行。
- 图表使用 [ECharts](https://echarts.apache.org/) 5.5，经 CDN 加载。
- 迷你趋势折线使用内联 SVG 绘制，避免大量图表实例带来的性能开销。
- 服务以生产模式静态直出，无热重载，规避容器环境下的内存峰值问题。

## 常见问题

**页面打开是空白？**
项目依赖 ECharts CDN。离线或网络受限时会无法渲染图表，请确保能访问 CDN，或自行把 ECharts 脚本下载到本地并改写 `index.html` 里的 `<script src>`。

**数值看起来一直在跳？**
这是预期的演示行为：模拟引擎每 4 秒轮播涨跌榜、每 6 秒整体刷新并触发 odometer 数字滚动。要停止模拟，在 `index.html` 里停掉对应的定时器即可。

**手机上看表格很挤？**
基金列表在窄屏会自动切换为卡片视图。若仍拥挤，请在 `<meta name="viewport">` 之后检查是否被外部样式覆盖了媒体查询断点。

**交易状态是按什么判断的？**
按真实时区实时计算 A股 / 港股 / 美股 / 日股的盘中、休市状态，并非写死的时间表。跨时区或调整系统时间会导致显示变化，属正常现象。

**能接真实行情吗？**
本项目只做前端演示，没有后端与行情源。要接真实数据需自行增加数据接口层，并替换 `index.html` 内的模拟数据生成逻辑。
